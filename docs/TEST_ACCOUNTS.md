## 🌱 시드 데이터 실행 방법

### ⚠️ 중요: 프론트엔드 모달에 표시된 계정 사용 시

프론트엔드 `TestAccountModal`에 표시된 계정을 모두 사용하려면:

```bash
cd be
npm run seed  # testSeed.ts 실행
```

**이렇게 하면 생성되는 계정:**

- ✅ customer1@test.com ~ customer10@test.com (비밀번호: 1q2w3e4r!)
- ✅ driver1@test.com ~ driver10@test.com (비밀번호: 1q2w3e4r!)
- ❌ driver0@test.com은 생성되지 않음 (seed2.ts에서만 생성됨)

**참고:** `driver0@test.com`을 사용하려면 `seed2.ts`를 실행해야 하지만, 이 경우 `driver1~10` 계정이 삭제됩니다.

### 1. testSeed.ts 실행 (기본 테스트 데이터)

```bash
cd be
npm run seed
# 또는
npx prisma db seed
```

**생성되는 데이터:**

- 고객 10명 (customer1@test.com ~ customer10@test.com)
- 기사 10명 (driver1@test.com ~ driver10@test.com)
- 주소 5개
- 찜하기 데이터 (고객 5명 × 기사 3명씩)
- 리뷰 데이터 (100개)
- 견적 요청 및 견적 데이터

### 2. seed2.ts 실행 (통합 테스트 데이터)

```bash
cd be
npm run seed2
```

**주의:** `seed2.ts`는 실행 시 "driver"로 시작하는 모든 계정을 삭제합니다.
따라서 `testSeed.ts`로 생성한 `driver1~10` 계정이 삭제됩니다.

**생성되는 데이터:**

- 고객 8명 (SEED2: testuser0~4@test.com + SEED3: user0~2@test.com)
- 기사 4명 (driver0@test.com ~ driver3@test.com)
- 주소 5개
- 일반 견적 요청 8개
- 지정 견적 요청 5개
- 완료된 견적 3개

## 📊 생성되는 테스트 데이터

### testSeed.ts

#### 1. 사용자 데이터

- **고객**: 10명
  - 각 고객마다 프로필 정보 (이동 유형, 현재 지역, 이동 날짜)
  - 랜덤한 이동 유형 조합 (HOME, OFFICE, SMALL)
- **기사**: 10명
  - 각 기사마다 프로필 정보 (닉네임, 경력, 소개, 이동 유형, 서비스 지역)
  - 경력: 1~10년
  - 서비스 지역: 서울, 대구, 경기도, 부산

#### 2. 주소 데이터

- 서울특별시 강남구 테헤란로 1길 101호
- 대구광역시 수성구 범어로 10 202호
- 경기도 수원시 장안구 정자동 88 303호
- 부산광역시 해운대구 해운대로 570 404호
- 서울특별시 중구 을지로 100 505호

#### 3. 찜하기 데이터

- 고객 5명이 각각 3명의 기사를 찜하기로 등록

#### 4. 리뷰 데이터

- 완료된 견적에 대한 리뷰 100개
- 평점: 1~5점 (랜덤)
- 각 기사의 평균 평점 자동 계산

#### 5. 견적 요청 및 견적 데이터

- **대기 중인 견적 요청**: 5개
  - 각 요청마다 2개의 견적 제안
  - 견적 반려 기록 1개 포함
- **지정 견적 요청**: 5개
  - 특정 기사에게 지정된 요청

## 🎯 주요 기능 테스트 시나리오

### 1. 고객 로그인 및 견적 요청

```
1. customer1@test.com / 1q2w3e4r! 로 로그인
2. 견적 요청 페이지로 이동
3. 이사 정보 입력 (출발지, 도착지, 날짜 등)
4. 견적 요청 제출
5. 여러 기사로부터 견적 제안 확인
```

### 2. 기사 로그인 및 견적 제안

```
1. driver1@test.com / 1q2w3e4r! 로 로그인
2. 견적 요청 목록 확인
3. 견적 제안 작성 및 제출
4. 고객이 견적 수락 시 알림 확인
```

### 3. 찜하기 기능

```
1. customer1@test.com 로 로그인
2. 기사 목록 페이지에서 기사 확인
3. 찜하기 버튼 클릭
4. 찜하기 목록에서 확인
```

### 4. 리뷰 작성

```
1. customer1@test.com 로 로그인
2. 완료된 견적 확인
3. 리뷰 작성 페이지로 이동
4. 평점 및 리뷰 내용 작성
5. 리뷰 제출
```

### 5. 알림 기능

```
1. 고객/기사 로그인
2. 견적 제안, 수락, 거절 등의 알림 확인
3. 실시간 알림 업데이트 확인
```
